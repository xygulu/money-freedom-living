## 1. 产品全景与信息架构

产品 = **一间只属于你的、关于钱的房间**。移动优先（微信内打开为主场景），底部 Tab 四个：

```
落地页 /                     未注册用户入口
  └─ /onboarding            金钱关系体检（3 步向导）→ 生成画像
      └─ /portrait          你的金钱画像（起点）

已进入用户（底部 Tab）：
┌──────────────────────────────────────────┐
│   旅程        对话        日记       我的   │
│ /journey     /chat     /journal     /me   │
└──────────────────────────────────────────┘

/journey    旅程主页：今日三件事 + 四阶段地图 + 当前位置
/chat       AI 陪伴对话（产品核心）
/journal    金钱心事（日记 + AI 回应）
/me         档案入口、VIP 订阅 /vip、设置
/timeline   成长足迹（v1.5，从 /journey 进入）
```

**MVP 页面清单**：`/`、`/onboarding`、`/portrait`、`/journey`、`/chat`、`/journal`、`/vip`、`/me`。`/timeline` 与信件完整仪式放 v1.5。

设计基调：暖、静、私密。**没有排行榜、没有社交元素、没有分数仪表盘**——画像用文字不用数字打分，纪念日用心印不用进度条焦虑。

## 2. 首次会话流程（效果保证的第一现场）

目标：**10 分钟内让用户感到"它说中了我"**。

```
落地页 CTA「看看你和钱的关系」
   ↓
① 问卷（6 题，2 分钟）→ ② AI 初谈（3-5 轮，5 分钟）→ ③ 生成画像（30 秒）
   ↓
/portrait 画像页「这就是你的起点」→ CTA「和它聊聊」→ /chat 第一次对话
```

### ① 问卷：收集"具体的事"，不是量表分数

选择题为主 + 1 道开放题，每题都要能落到档案：

| # | 问题 | 形式 | 进档案的字段 |
|---|---|---|---|
| 1 | 最近一次为自己买"纯粹想要"的东西，是什么时候？ | 四选一（这周/这个月/想不起来/不敢想）+ 可补充 | specific_moments |
| 2 | 打开余额的时候，你的第一感觉是？ | 四选一（平静/逃避不想看/心慌/无所谓反正不够） | money_feeling |
| 3 | 小时候家里，关于钱你印象最深的一句话或一个画面？ | 开放题（核心题） | script_source |
| 4 | 钱到账的那天（发薪日），你的第一个动作是？ | 四选一（先还账/先存起来/犒劳自己/没什么感觉） | payday_habit |
| 5 | 你最羡慕什么样的人和钱的关系？ | 四选一（松弛不纠结/敢花/很会赚/不被钱支配） | aspiration |
| 6 | 最近一次为钱心慌或内疚，是什么时候、因为什么？ | 开放题（核心题） | concerns 种子 |

### ② AI 初谈：追问一个点，深挖而不是重复问

AI 读问卷答案，挑**最有情绪重量的一处**追问 3-5 轮（例如：用户第 3 题写了"我妈说咱家不配"→ AI 只谈这个）。要求：
- 只深挖一个点，让用户感到"它在认真听"而非"走流程"
- 全程不给建议、不安慰、不纠正——只反映和好奇（"后来那句话还留在你心里吗？"）
- 谈话结束 AI 内部整理：这段对话暴露了什么脚本、哪三个具体瞬间值得记住

### ③ 画像生成：见 §3

## 3. 金钱画像（产品的灵魂物件）

**用文字，不用分数。** 用户看到的是这样一页：

```
┌────────────────────────────────────┐
│         你的金钱画像                 │
│                                    │
│  【你的金钱底色】                    │
│  你买东西之前会先看价格标签，放进     │
│  购物车，过两天再默默删掉。你不是     │
│  没有钱，是花钱那一刻总有个声音说     │
│  "再省一点"。……（100-200 字，       │
│  第二人称，全部来自 TA 自己说过的话） │
│                                    │
│  【你和钱的三个瞬间】                │
│  · 小时候听到"咱家不配"的那个傍晚     │
│  · 上个月退掉那双鞋时的松了口气       │
│  · 发薪日先还花呗的长舒一口气         │
│                                    │
│  【你心里的一条旧脚本】               │
│  "不配享受"——它来自很久以前，        │
│  但它不是事实。                      │
│                                    │
│  【给未来的你】                      │
│  2026 年 9 月 11 日，你从这里出发。   │
│                                    │
│      [ 和它聊聊 ]  （→ /chat）      │
└────────────────────────────────────┘
```

四个部分的设计意图：

- **金钱底色**：画像的说中感所在。规则：**每句话必须能追溯到用户自己说过的话**，禁止空泛性格标签（"你有时焦虑"这类句子一律不允许）
- **三个瞬间**：从问卷和初谈中提取的 3 个具体场景——这是后续**回访机制的数据源**（阶段推进时 AI 回访这些瞬间）
- **旧脚本**：点出 1 条（最多 2 条）限制性信念，语气是"看见"不是"诊断"
- **给未来的你**：画像页自动成为时间线的第一个节点

画像不是一次性的：阶段毕业时更新版本，v1.5 做前后对比。

## 4. 四阶段旅程设计

每阶段在 `content/journey/` 有一个定义文件（schema 见 §8），包含：目标、练习、AI 姿态、毕业标志、仪式。以下是 v1 内容设计：

### 阶段 1 · 看见（免费，约 2 周）

- **目标**：如实地看见自己和钱的关系，不评判
- **练习**：① 完成体检与画像 ② 金钱记忆回溯（和 AI 聊最早的金钱记忆）③ 一周观察任务（"这周留意你什么时刻会想起钱"，回来告诉它）
- **AI 姿态**：倾听者、镜子。**只反映，不建议、不纠正、不急着正向**
- **毕业标志**：能说出自己的三个瞬间 + 认出至少一条旧脚本
- **仪式**：「给现在的自己」第一封信（AI 温柔回信）

### 阶段 2 · 松动（免费，约 3 周）

- **目标**：看见脚本从哪来；情绪被看见，松动就开始
- **练习**：① 童年金钱场景重访（陪 AI 重新走进那个画面）② **写给钱的一封信**（核心仪式，可以写愤怒、委屈、抱歉）③ "我一直不敢为自己做的那些小事"清单
- **AI 姿态**：陪伴者、见证者。接住情绪，**不催用户"走出来"**
- **毕业标志**：完成写给钱的信
- **仪式**：心印「看见来处」

### 阶段 3 · 练习（VIP，约 4 周，弹性最长）

- **目标**：用一个个小实验，建立和钱的新相处方式
- **练习**：① 允许清单（列出一直不敢为自己花的钱，从小额开始）② 每天一个微小实验（为自己花一笔纯粹开心的钱 / 享受一件免费的美好 / 对一笔支出说"值得"）③ 实验后回来记录感受，AI 接住每一次
- **AI 姿态**：教练 + 啦啦队。庆祝微小的突破；回访画像里的三个瞬间——"你说发薪日会心慌，这次发薪日呢？"
- **毕业标志**：完成 ≥7 个小实验，且回访中用户亲口说出变化
- **仪式**：心印「练习松弛」+ 画像 v2

### 阶段 4 · 活法（VIP，长期）

- **目标**：把松弛过成日常，定义属于自己的"不愁钱"
- **练习**：① 写下"我的不愁钱定义"（和多少钱无关）② 活法清单（日常化小实践，如每月一天"随心日"）③（可选）现实路径：收入与自由的轻量思考——**全产品唯一碰数字的地方，且碰得轻松**
- **AI 姿态**：陪练。话题从疗愈转向生活，定期回访活法践行情况
- **毕业概念**：无毕业，长期陪伴（防"痊愈即流失"）
- **仪式**：「给未来的自己」信，封存，约定半年后打开

## 5. 每日节奏

用户每天打开 `/journey`，看到三件事：

1. **今日一签**：从 `content/daily/` 素材池按日取一张书摘心法卡（按用户当前阶段加权抽取；素材池同时是公开获客内容的原料）
2. **今日微行动**：按当前阶段的练习生成（观察任务/小实验/随便聊聊）
3. **陪伴对话**：进入 `/chat`

对话开场由 AI 依据档案决定（优先级从高到低）：昨天微行动的回应 → 回访钩子（三个瞬间/开放中的困扰）→ 当前阶段引导 → 自由聊。用户随时可以完全不接引导。

**周期情绪锚点**（v1.5 起做召回）：发薪日、月底、大促、年底主动出现一句"今天是发薪日，这个月和钱处得怎么样？"

## 6. AI 成长档案（机制的地基）

### 数据结构（逻辑字段，物理表结构见 docs/03）

```
growth_profile
├── identity            user_id 或游客匿名 key（saas-kit 同款解析）
├── portrait            jsonb {底色, 三个瞬间[], 旧脚本[], 给未来的你, version}
├── concerns[]          具体困扰池 {内容, 状态: 开放/松动/化解, 来源时刻}
├── stage               1-4 当前阶段 + stage_started_at
├── memories[]          关键对话摘要（滚动，带日期，上限 N 条）
├── experiments[]       阶段 3 实验记录 {日期, 做了什么, 感受}
├── letters[]           信 {阶段, 内容, 状态: 封存/已开, AI 回信}
├── stamps[]            心印 {类型, 获得时间}
└── total_active_days   累计足迹（不是连续 streak）
```

### 记忆机制

- 每次对话结束后**异步**做摘要（不阻塞对话），追加进 `memories`；超过上限时滚动合并旧条目
- **上下文组装顺序**（每次对话）：`system(当前阶段引导语 + 创造者实践经验笔记)` → `画像` → `开放中的 concerns` → `近期 memories` → `最近对话轮次`

## 7. 配额与 VIP 门禁

原则：**免费用户不被硬墙挡住旅程，付费买的是更深的陪伴**（私人产品的付费应是"爱的供养"，不是"墙"）。

| 能力 | 游客 | 免费 | VIP |
|---|---|---|---|
| 体检 + 画像 | ✅ | ✅ | ✅ |
| 阶段 1-2 | ✅（体验） | ✅ | ✅ |
| 陪伴对话 | 每日 1 次 | 每日 3 次 | 无限 |
| 阶段 3-4 | — | — | ✅ |
| 日记的 AI 回应 | — | — | ✅ |
| 信件的 AI 回信 | — | ✅ 首封 | ✅ |
| 阶段深度报告 | — | — | ✅ |

- 门禁统一走 saas-kit `/api/quota/consume`（`kind=chat`），**重试/重新生成按钮同样过门禁**（哄哄踩过的坑，纪律条款）
- 游客身份 = saas-kit 匿名 cookie 方案，注册后档案无缝继承
- 阶段 1-2 全免费的理由：这是建立"它懂我"信任的关键体验，信任建立后阶段 3 的"每天陪练"才是订阅的自然付费点

## 8. 内容层规范（共创通道）

内容与代码分离，全部 git 管理。**用户的实践经验写进 `practices/` 即生效**。

### `content/journey/N-阶段名.md`

```yaml
---
id: 3
title: 练习
goal: 用小实验建立和钱的新相处方式
weeks: 4            # 预计时长（弹性参考值，非 deadline）
vip_only: true
exercises:          # 供每日微行动生成
  - 允许清单
  - 每日一个小实验
ai_stance:
  do: [庆祝微小的突破, 回访画像瞬间]
  dont: [给理财建议, 用分数衡量用户]
graduation: 完成 7 个小实验且用户说出变化
ritual: 心印「练习松弛」+ 画像 v2
---
（正文：这个阶段的引导语、话术示例、注意事项——AI system prompt 的直接原料）
```

### `content/daily/`（今日一签素材池）

每条一个文件或合并为 JSON 池：`{quote, source, reflection, stages: [适配的阶段]}`

### `content/practices/`（创造者实践经验笔记）

frontmatter 只要求 `date` + 可选 `tags` + `stage`，正文自由书写。AI 组装上下文时按当前阶段相关度取用（v1 全量注入，笔记多了再上检索）。

## 9. 版本切分

| 版本 | 范围 |
|---|---|
| **MVP（第一版）** | 落地页、体检+画像全流程、旅程主页（今日三件事）、对话（含档案与记忆）、日记（VIP 回应）、四阶段内容 v1、配额+VIP 支付、足迹简版 |
| v1.5 | 信件完整仪式（封存/开启）、画像前后对比、周期情绪召回（发薪日等）、公开获客内容板块 |
| v2 | 阶段深度报告、practices 检索、更多锚点场景 |

MVP 的验收标准一句话：**一个陌生人进来，10 分钟后被说中，三天后它还记得他**。
