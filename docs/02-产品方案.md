## 1. 定位与基本盘

**一句话**：不是教你赚钱，是陪你把你和钱的关系处好。

**基本盘**：

| 维度 | 定案 |
|---|---|
| 品类 | 关系陪伴（金钱关系），非理财工具、非课程、非咨询 |
| 用户 | 对钱有羞耻/回避/焦虑情绪的成年人（18+），单人私密场景 |
| 价值主张 | 每天一步真实的小行动 + 一个一直在的陪伴者 + 一份随时间生长的档案 |
| 收费 | 单档位 VIP 订阅（Creem），免费档可完整走完一本书 |
| 平台 | Web 优先（PWA 友好），iOS 规划中 ⏸ |

**题材三理解**（产品一切语气的来源）：
1. **反理财书**：不讲投资、不荐股、不算账。用户缺的不是知识，是「知道但做不到」。
2. **情绪消费**：买的不是效率，是「被看见」和「不丢人」。减压、私密、无评判。
3. **私密题材**：钱背后是家庭、羞耻、比较。单人对话场景，**不做社区、不做排行、不可分享成绩**（已否决，见 §17）。

**定位三问定案**：用户为什么来（钱让他难受）／为什么留（被看见 + 档案在生长）／为什么付费（想把关系真正处好，免费档走不完自我 section 的深度）。

**效果四保证**（对外承诺的边界）：不保证赚钱、不保证戒掉乱花、不保证修复家庭关系；保证的是——每天一步是真实的小行动、每一步被看见、看见会积累成档案、档案只增不减。

**留存五机制**：① 每日一步（低成本启动）② 陪伴者在场（关系感）③ 灯与阶段（可见进度）④ 档案只增不减（沉没资产）⑤ 触达七节点（断点拉回，见 §11）。

> 定位层是原则，无独立实现对象；其落地情况由后续各节核验覆盖。

## 2. 产品形态与陪伴机制

**四层陪伴机制**：

| 层 | 机制 | 现状 |
|---|---|---|
| 做 | 每日一步：从当日卡取一个真实小行动，做完记录 | ✅（§6） |
| 说 | 被看见：陪伴者对话，接住感受不评判 | ✅（§8） |

| 留 | 长期档案：画像、报告、足迹、信件，只增不减 | ✅（§5、§9） |

**共创机制（内容生产侧，非用户功能）**：跨书抽象三层——L1 题材域（钱与安全/父母/自我价值…六命题）、L2 命题线（threads）、L3 单书内容（content/books/）。命题是桥：灯从书的阶段拆出来挂到命题上，跨书可交叉印证。选书铁律：第二本只在第一本的灯亮到一定程度后出现，**不设日历、不催**（§10）。
