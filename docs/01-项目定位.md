### 命名历程（存档备查）

`financial-freedom` → `carefree-living` → `no-money-worries` → `money-free-living` → `financial-freedom-living` → **`money-freedom-living`（定名）**

定名理由："financial freedom" 是严格的财务状态（被动收入 > 支出），会框死在搞钱路径；"money freedom" 是"和钱的关系自由"，心态与路径都覆盖，且贴合原书"心态类而非理财教程"的气质（money mindset / money healing 同款构词）。中文书名保持原书名。

## 2. 题材理解

这本书是**"反理财书"**：不讲复利公式，讲你和钱的关系——不硬拼努力、松弛的"吸金体质"、随心生活。它是**情绪消费，不是知识消费**。这个判断决定了产品形态的取向（轻、暖、可分享，而不是表格和专业术语）。

## 3. 我方现有优势（复用资产）

- **哄哄模拟器**（/root/honghong，生产运行中）验证过的完整路径：轻互动 + LLM 对话 + 病毒传播 + 配额订阅变现
- **saas-kit**（/root/saas-kit）：Neon + Better Auth + 多平台支付 + 每日配额，就是为"新项目直接复用"抽的
- 现成 LLM 网关（Anthropic 兼容，glm-5.3-flash，关 thinking）
- 强制 pnpm；Next.js App Router 栈（注意 AGENTS.md 的破坏性变更警告）

## 4. 形态设计空间（讨论中的排序）

| 排序 | 形态 | 角色 | 备注 |
|---|---|---|---|
| ① | **互动测试 / 轻游戏**（"测你的金钱人格 / 吸金体质 / 金钱焦虑指数"，出可分享结果卡） | 裂变拉新 | 哄哄同款打法，结果页即内容 |
| ② | **AI 金钱咨询师**（用书的口吻陪你聊钱，先松心态而非给理财建议） | 体验深度 + 付费点 | 免费每日 3 次 → VIP 无限，saas-kit 配额严丝合缝；有 token 成本 |
| ③ | 财务自由计算器（"要攒多少才敢退休"+ 自由进度条） | 引流钩子 | 最轻，但同质化严重，只当入口 |
| ④ | 内容站（书摘卡片、每周金钱心法） | 留存 | 获客弱，后置 |

**当前倾向**：① + ② 组合起步（测试拉新 + AI 对话留客变现），③④ 后置。技术上约等于哄哄模拟器复用，可快速上线验证。

## 5. 待决问题（下次继续）

1. **给谁用、在哪传播**：微信里转着玩的年轻人（对标哄哄路线），还是自己沉淀实践的书粉社区？
2. **敢不敢烧 LLM**：AI 对话是差异点但有 token 成本；纯测试几乎零边际成本。
3. **变现节奏**：第一天就接 saas-kit 的 VIP，还是先免费跑数据再接？

## 6. 命名之外已否决的方案（防走回头路）

- ~~`no-money-worries`~~：没突出"活法"
