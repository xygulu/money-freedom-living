### 命名历程（存档备查）

`financial-freedom` → `carefree-living` → `no-money-worries` → `money-free-living` → `financial-freedom-living` → **`money-freedom-living`（定名）**

定名理由："financial freedom" 是严格的财务状态（被动收入 > 支出），会框死在搞钱路径；"money freedom" 是"和钱的关系自由"，心态与路径都覆盖，且贴合原书"心态类而非理财教程"的气质（money mindset / money healing 同款构词）。中文书名保持原书名。

## 2. 题材理解

这本书是**"反理财书"**：不讲复利公式，讲你和钱的关系——不硬拼努力、松弛的"吸金体质"、随心生活。它是**情绪消费，不是知识消费**。

关键推论（决定了整个产品方向）：

- **和钱的关系是心事，不是谈资**。金钱焦虑、匮乏感、"我不配"是羞耻感话题，没人想在朋友圈晒自己的金钱画像——**题材天然私密**，裂变传播路线在这个题材上失灵（哄哄是喜剧题材，"看我怎么哄"是社交表演，两者本质不同）。
- 因此产品形态取向：**轻、暖、私密、被记住**，而不是热闹、可晒、病毒式。

## 4. 定位定案（原待决三问的答案）

| 问题 | 结论 | 理由 |
|---|---|---|
| 给谁用、在哪传播 | **私人空间，用户为自己而来**；获客走「公开的内容，私人的空间」：公开层写钱的心事（"为什么你舍不得给自己花钱"类文章/书摘卡），私人层是自己的房间 | 题材私密，裂变失灵；内容获客慢但来的都是带着具体困扰的人，质量极高 |
| 敢不敢烧 LLM | **必选，且 AI 对话就是产品主体** | 私人定位下对话不是"付费点"而是产品本身 |
| 变现节奏 | **VIP 早接** | 量小但单用户深；流量小 token 烧不了多少，深度用户付费意愿反而强。免费：每日 3 次对话 + 第 1 阶段体验；VIP：无限对话 + 全部阶段 + 日记 AI 回应 + 阶段深度报告 |

**形态思考的演变**（存档）：最初方案是「测试裂变 + AI 咨询师」组合（哄哄同款打法，测试管拉新、对话管变现）→ 用户定位为"私人个人的产品"后，两模块合并升级：测试从"晒结果卡"变成"私人关系体检"（只给自己看，作为对话底稿与日后对比基线），AI 对话从"付费点"升级为产品主体。

## 5. 产品形态：陪伴成长机制（四层）

产品 = **一间只属于你的、关于钱的房间** = 一段有阶段、有节奏、被见证的成长旅程。

### 第一层：成长路径（纵向——你走到哪了）

把书的脉络结构化成四个阶段，逐段解锁：

| 阶段 | 主题 | 核心内容（源自书的逻辑） |
|---|---|---|
| 1 看见 | 你和钱现在的样子 | 关系体检 → 你的金钱画像；焦虑从哪来；最早的金钱记忆 |
| 2 松动 | 看见背后的故事 | 童年金钱脚本（"钱来之不易""我不配"）；**写给钱的一封信**；释放紧绷 |
| 3 练习 | 和钱的新相处方式 | 允许自己享受；感恩练习；每天一个小实验 |
| 4 活法 | 你的不愁钱活法 | 落到日常的实践；定义属于你的"不愁钱"；（可选）通往自由的现实路径 |

### 第二层：每日节奏（横向——今天回来做什么）

- **今日一签**：一句书摘心法（素材池同时是公开获客内容的原料）
- **陪伴对话**：和 AI 聊今天的钱心事（配额扣在这里）
- **微行动**：当天一个小练习，做了就记上

### 第三层：见证与仪式（为什么值得留下来）

- **成长时间线**：走过的每一步、被点亮的时刻
- **画像对比**："30 天前 vs 现在"，变化看得见
- **阶段仪式**：每完成一阶段给自己写一封信存起来（书写疗愈是这本书的原生方法，AI 做温柔的回应者）；完成有「心印」——温暖向纪念，不做游戏化等级感

### 第四层：AI 陪伴的记忆（机制的地基）

AI **认识你**：画像、所处阶段、日记、关键对话摘要沉淀为**成长档案**，每次对话注入上下文——它记得你上次说到什么、知道你卡在哪、按你的阶段引导。**被记住的感觉是私人产品最强的粘性**。技术上唯一的新东西就是这张成长档案表（Neon 现成能力）。

## 6. 效果与留存设计

两个问题本是一体：**心理类产品的留存靠"感知到变化"**——感知不到效果什么都留不住，感知到就舍不得走。

### 效果四保证

1. **方法论被验证**：书的路径畅销十年（豆瓣 8.3、心屋仁之助几千例咨询），不发明心理学。
2. **首日说中感**：10 分钟内的 aha = "它真的懂我"。体检收集**具体的事**而非量表分数；AI 画像必须具体到行为（"你买东西先看价格标签，放进购物车，过两天默默删掉"），说中一件具体的事胜过十句"你有时会焦虑"。
3. **具体事回访**：入档时记下 3 个具体困扰，AI 后续回访（"还记得你说发薪日会心慌吗？这个月怎么样了？"）——真实咨询师的工作方式，用户亲口说出变化即效果兑现。
4. **阶段末回望仪式**：画像前后对比 + AI 整理变化时刻，用他自己说过的话对比。

### 留存五机制

1. **功课—回应循环**：对话结束留一个微小的观察任务，明天回来先接住回应——未完成感是最自然的日活机制（心理咨询 homework 的用法）。
2. **关系记忆**：离开两周回来，它说"你上次那件事，后来呢？"；召回文案不说"已断签 3 天"（惩罚感），说"它还记得你的心事"（关系感）。
3. **周期情绪锚点（题材独有红利）**：金钱情绪有天然日历——**发薪日、还贷日、月底、大促、年底**。发薪日主动出现："今天是发薪日，这个月和钱处得怎么样？"留存跟真实情绪周期走，不靠意志力打卡。
4. **累计足迹，不做连续打卡**：streak 断了人会破罐破摔；用"旅程足迹"（累计）代替连续打卡，断几天路还在。
5. **"好起来"的人有下一站**：防心理产品隐形流失（感觉好了=不需要了）——阶段 4 接住他们，从"疗愈"毕业进入"生活"，产品角色从疗愈者升级为活法陪练。

## 7. 共创成长机制：内容与代码分离

创造者本人正在实践书中方法、是第一个用户；产品必须能随他对书的理解和应用而成长，**他的实践经验要能零成本融入产品**。

原则：**代码是壳，书的内容和创造者的实践是活水**。

### 内容层（git 管理，markdown 为主）

```
content/
├── journey/          # 四阶段定义：每阶段的目标、心法、练习、AI 引导语
│   ├── 1-看见.md
│   ├── 2-松动.md
│   └── ...
├── daily/            # 今日一签：书摘 + 心法素材池
└── practices/        # 创造者自己的实践经验笔记（融入通道）
    ├── 2026-09-08-允许自己享受一次.md
    └── ...
```

### 融入方式（零成本）

实践中有感悟（某个方法怎么起效、哪里与书不同、自己的变体）→ 随手写一条 markdown 丢进 `practices/` → git 提交即生效，不改 prompt、不改代码。

### AI 的注入

组装对话上下文时注入两层：**当前阶段的旅程内容 + 创造者的实践经验笔记**。市面上的 AI 陪伴是"读过书的 AI"，我们的是"**正在这样活着的 AI**"——它说的不只是书上的话，还有方法在真实人生里的体验。（笔记多了以后再上检索，不预支复杂度。）

### 版本化的宽容度

创造者还没读完书——这恰是对的节奏：先按书整体框架搭 v1 内容，读到哪、悟到哪，内容跟到哪，产品永远贴着真实理解走，不跑在空壳方法论上。
