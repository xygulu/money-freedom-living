## 2. 信息架构：一级入口 4 → 3

```
┌────────────────────────────────────────────┐
│         路              聊              我   │
│  （今天这一段）  （陪伴对话·产品主体）  （档案） │
└────────────────────────────────────────────┘
```

- **路**＝被动模式：打开就被接住、就被给一段（承载 `docs/05 §8` 的"开 / 做 / 合"）
- **聊**＝主动模式：我想说点什么（现状 `/chat`，保留）
- **我**＝档案模式：只在用户主动想回看时出现

**导航纪律**：新功能**不得直接进一级导航**——只能从"路"上长出来（一段 / 一个机关）、从"聊"里长出来（对话动作），或进"我"。一级入口永远 3 个。

### 2.1 页面去向（现状 → 目标）

| 现状页面 | 去向 | 说明 |
|---|---|---|
| `/`（落地页） | 未登录＝落地页；**已登录直接是"路"** | 已体检用户不再需要中间页（现状已部分如此） |
| `/onboarding` | **保留但重排**：按 `docs/05 §7`「先被说中 → 再注册 / 同意 / 定价」 | 敏感信息同意弹窗挪到"被说中"之后 |
| `/journey` | **＝首页「路」**（`docs/05 §8` 的一段） | 三张卡片退场 |
| `/chat` | **Tab 2「聊」** | 不变 |
| `/journal` | **降级进「我」**＝"我写过的话" | 写字本就是"叙"的一部分，不占一级入口 |
| `/timeline` | **并入「你走过的路」**（`docs/05 §3.5` 里那个唯一露出书的页面） | 时间线＝路的纵轴 |
| `/letters` | **机关节点的动作**（D14 / D30 / D66 / D90） | 信是仪式，不做常驻功能页 |
| `/portrait` | **「我」的第一屏**（我的镜子） | 画像仍是灵魂物件，不占主导航 |

| `/chat/history` | 「聊」内只读索引 | 保留回看能力 |

### 2.2 首页「路」的结构（自上而下）

```
今日日期（不出现书名 —— 依 docs/05 §3.5：书只在「你走过的路」露出）
┌──────────────────────────────┐
│ 你上次留在这里：                │   ← 昨日回响（没有就留白，不占位）
│ "发薪日我居然没先还花呗"         │
└──────────────────────────────┘
┌──────────────────────────────┐
│ 开：今日一签                    │
│ 做：一个 2 分钟动作             │   ← docs/05 §8 的「开 / 做 / 合」
│ 合：一句话被接住 +「今天到这里」 │
└──────────────────────────────┘
· · · ● ● ● ● ● ● ● ○ ○ ○ ○ ○      ← 走过的格子用用户自己的原话做纹理
```

**硬规矩**：只有**一个主动作**（"说说今天"）／无红点无未读／无任务列表／**书名不出现**。

### 2.3 「合」的那一步＝三件事压成一屏（不做多步流程）

```
① 我做了   [✓ 就是这个]  [换一个]  [今天跳过]    ← 一次点击即确认
② 我想到   [ 一句话 / 一张图 / 语音 ]           ← 「证」
③ 脑子里第一句话 [ 一句话，可跳过 ]              ← 「叙」＝认知层入口（见 §4）
          [ 交给他 ] → 即时见证回应（现状已有）+ 这一段收束
```
②③ 可跳过；③ **跳过不惩罚、不暗示"建议填写"**（它是照见工具，不是作业）。

## 3. 「我」的结构（档案模式）

```
我
├─ 我的镜子     画像（当前版）· 命题坐标（六命题上"我到这儿了"）
├─ 我说过的话   原话收藏（《我脑子里的那几句话》滚动版）
├─ 我走过的路   跨书站点 · 机关节点 · 回望图 ← 书唯一露出处（docs/05 §3.5）
├─ 我的记录     日记 / 信 / 对话索引（现状内容聚合，不再抢主界面）
└─ 设置与账号   VIP · 导出 · 删除 · 恢复码 · 语言 · 邮件与通知偏好
```

**命题坐标 = 用户级主进度条**（`docs/05 §3.1/§3.2`：书是"区域"不是进度条；灯从书的阶段里拆出来挂命题）。
→ 界面呈现：六条命题各有"我到这儿了"的刻度；**没有"书的完成度"这个概念**。

## 4. 认知层验收指标 L4 / L5 / M（**服务器文档目前缺这一块**）

依据：知识库 `10-2_认知内化机制_方法与验收`（今天的定案）。这三个是判断"机制成不成立"的**主指标**（行为层必须与认知层成对看，只测行为会得出假结论）。

| 指标 | 定义 | 采集落点 | 用户成本 |
|---|---|---|---|
| **L4 迁移** | 没人提示，主动用新框架解释了一件**新事** | ① AI 在对话里识别到"意外用上了新说法"时，一键记下 ② 「合」那一步可手动标记 | 1 次点击 |
| **L5 停顿** | 原来自动化的反应，现在**能停一下**了 | 「合」的第 ③ 问（每天出现，可跳过） | 1 句话 |
| **M 恢复时间** | 掉回旧模式后，**恢复得更快** | **不新增交互**：由"掉回旧模式的记录"与"下次出现的时间差"自动计算 | 0 |

**原则**：认知层采集**不新增第三个日常任务**。能自动算的自动算（M）；能一句话问到的绝不设计成表单（L5）；能一键记的绝不要求用户写（L4）。

**与 `docs/05 §4.5`「6 个阶段验证节点：零 DDL」的关系**：节点（D7/14/21/30/66/90）是**出结论的时刻**；L4/L5/M 是**结论的依据**（也是 20-1 判定表里"机制成立 / 空转 / 无效"三档的判据）。二者必须成对存在，缺一个就只能退回去看行为完成率。

**反指标（必须一起记）**：**形式化打卡率**（只写"已完成"、无细节的占比）与**敷衍率**——高于 30% 说明机制在空转。

## 5. 机关节点（D7/14/21/30/66/90）的形态

| 规则 | 内容 |
|---|---|
| **不是报告** | 节点不做"你进步了 30%"这类结论；**给物件，不给结论**（`docs/05 §8.1`：解读权归用户） |
| **物件是什么** | 把他自己的原话按时间排出来 + 回望图（`/portrait/compare`、`/journey/changes` 归到此处） |
| **越往后越轻** | D3–D14 是**节奏节点**（密度高、决定留存）；D21 之后是**观察节点**（每节点只问 1–2 句，不加动作量） |
| **允许提前收敛** | 任一阶段结论明确（成立 / 不成立）即停，不必跑满 90 天 |
| **出口** | 每个节点都要有"今天不聊"的出口 |

## 6. 四条自检（设计评审 / 验收时逐条跑）

- [ ] **盖住书名**：首页截图上的书名全部盖住，用户仍清楚"今天做什么、我走到哪了"
- [ ] **一个主动作**：首页只有一个主按钮
- [ ] **3 分钟**：从打开到"合"完成 ≤3 分钟（含第 ③ 问）
- [ ] **断 30 天回来**：界面上不出现任何"你错过了 / 已断签 / 补上"字样

## 7. 与 `docs/02 §12` 目标口径的关系（内部指标 vs 体验目标）

`docs/05 §8.2` 的"目标口径修正"（不把"每天主动使用"当目标）**与验证需求不冲突，但要补一句**：

- **体验目标**（对外、进界面与文案）＝ 每次回来有确定的质量 + 想面对钱的那一刻第一个想到它
- **内部验证指标**（不进界面、不进文案、不进触达）＝ **每日日课完成率**（"合"那一步完成 = 1 天），以及 L4 / L5 / M 随时间的序列

理由：认知层证据是**时间序列**（停顿要逐日看、恢复时间要趋势、迁移要间隔出现），一周来一次采不到。**内部测频率 ≠ 对外追频率**：前者是机制验证的必要条件，后者正是 §8.2 要避免的东西。
