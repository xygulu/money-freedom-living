## 1. 目标骨架（一句话）

> **打开就是「今天这一步」；往前只有下一步；想说话旁边有人（右下角常驻）；回头看，路就在脚下。**

一级结构从 4 个降为 **1 个真入口 + 1 个存档**：

```
取消底部 4 Tab（旅程/聊聊/心事/我的）
├── / 或 /journey   →  「一幕」：今天这一步（唯一主界面）
├── 右下角常驻      →  「一人」：陪伴者（不是 Tab，是场景里的一个存在）
└── /archive（新增）→  「一存档」：回看与设置（只在用户主动想回看时进）
```

---

## 2. 红线（违反即打回，不要自行放宽）

- **无红点、无未读计数、无徽标**
- **无百分比、无"还差几天"、无连续天数、无排行榜、无成就**
- **首页不出现书名**（决策 #31）、**不出现任务列表**（今天永远只有一件事）
- **"只看看"永远有出口**（首页有，机关时刻也有）
- **永不出现"你还没做"式完成度指责** —— ⚠️ **唯一例外见 §6**（用户 2026-09-14 明确要求的那一处）
- **认知层指标（L4/L5/M）不进界面、不进文案、不进触达**，只进数据表

## 4. 一屏放下：工程硬约束（带实测数据）

原型里已验证过的做法：

```css
/* 一幕 = 整屏；路贴底；剩余空白平分，避免中间一大块空 */
#one-screen{display:flex;flex-direction:column;min-height:100dvh;padding-bottom:82px}
#one-screen .path{margin-top:auto;padding-top:14px}
#one-screen .act, #one-screen .mirror{margin-top:auto}
.daily{font-size:clamp(19px,5vh,25px);line-height:1.5}
@media (max-height:760px){ /* 再紧一档 */ }
@media (max-height:600px){ /* 极短屏：隐藏辅助提示行 */ }
```

**实测阈值**（Chrome，手机宽 390，2026-09-14）：

| 手机可视高度 | 是否需要下滑 |
|---|---|
| 845 / 757 / 693 / 613 / **580** | **都不用** |
| ≤ 533 | 轻微下滑（可接受） |

**验收方式（必须用这个，不要用截图）**：

```js
document.documentElement.scrollHeight <= window.innerHeight + 1   // 必须为 true
```

> ⚠️ **不要用固定高度的 headless 截图判断"屏内留白/能否一屏"** —— 实测会误判（验收侧踩过）。
> ⚠️ Chrome headless 最小窗口宽度是 **500px**，`--window-size=390` 拿到的仍是 500 的视口。

## 6. 「有话要说」：触发、纪律、以及一处**用户明确要求的例外**

**三种合法触发**（内容只能来自用户自己）：
1. 他自己说过"想试"的那件事
2. 他自己的日历（发薪日 / 月末 / 大促）
3. 他上次说了一半的那句话

**⚠️ 用户 2026-09-14 明确要求的例外（已按用户要求实现，不要再自行改回）**：
> 球的"有话要说"可以用「**今天这一步你还没做**」这句原话。

- 这**撞了本项目原有的触达纪律**（永不说"你还没做"）。验收侧已当场把代价讲清，**用户拍板保留**。
- → 处理方式：**按用户要求实现**，同时在数据上记为**待验证假设**：
  **文案类型（完成度陈述 vs 状态陈述）对留存的影响，用数据判，不用争论判。**
- 若日后要做 A/B：这是现成的第二个可归因变量（第一个是"呈现层：文字 vs 图形隐喻"）。

**频次纪律（定死，防止变成催促）**：
1. 同一件"要说的话"**只晃一次**；点开过或忽略过，**当天不再晃**
2. 晃完立即回安静，**不重复、不连续**
3. 他先开口时，**必须带"今天不聊也行"的出口**

**能力边界（必须让 CC 知道）**：
> 小人的晃动**只在用户已经打开产品时可见** → 它**不是召回手段**；召回只有**邮件/系统通知**。
> 别拿它当日活抓手，也别因此加推送。
